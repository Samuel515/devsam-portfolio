# devsam-portfolio

Personal portfolio for **Samuel Ogbodo**, fullstack software engineer and co-founder & CTO of VerityWave Innovations.

Live at **[devsamc.xyz](https://devsamc.xyz)**. Companion browser-only tools will live on their own subdomains under `devsamc.xyz`.

## Stack

- [Astro](https://astro.build) 7, fully static output with near-zero client JavaScript
- Tailwind CSS v4 with design tokens for dark and light themes
- React integration installed for future interactive islands (none are used yet)
- Geist and Geist Mono, self-hosted through Fontsource
- `@astrojs/sitemap`, Open Graph and Twitter cards, and Person / WebSite JSON-LD
- Hosted as static files on Cloudflare Pages

## Run locally

Requires Node.js 22 or newer.

```sh
npm install
npm run dev        # http://localhost:4321
npm run build      # type-checks with astro check, then builds to dist/
npm run preview    # serves the production build
```

## Editing content

All copy and data lives in [`src/data/site.ts`](src/data/site.ts): hero text, stats, products, client work, skills, experience, education and contact details. Components in `src/components/` only handle layout.

Contact links (`email`, `linkedin`, `github`) are empty until you fill them in. Empty links are hidden on the live site and shown as an amber `TODO` in `npm run dev`.

### Portrait

The About section uses [`src/assets/samuel-ogbodo.jpeg`](src/assets/samuel-ogbodo.jpeg). Replace that file with a new photo of the same name, ideally 4:5 and at least 1600 × 2000 px. Astro generates the AVIF, WebP and JPEG sizes at build time.

### Project screenshots

Screenshots in `public/projects/` are captured from the live sites with the locally installed Microsoft Edge. Cookie banners are hidden automatically.

```sh
npm run screenshots                 # all sites
npm run screenshots veripay alidu   # only the named sites
```

The list of sites is at the top of [`scripts/screenshots.mjs`](scripts/screenshots.mjs).

### Social card and icons

`public/og.png` (1200 × 630) and `public/apple-touch-icon.png` are generated by `npm run brand` from [`scripts/brand.mjs`](scripts/brand.mjs). The tab icon is `public/favicon.svg`.

## Section links

In-page links use a query parameter instead of a hash, for example `devsamc.xyz/?about`. A script in [`src/layouts/Base.astro`](src/layouts/Base.astro) scrolls to the matching section and resets the address bar to `/` as soon as the section is reached. Shared links such as `/?contact` work the same way on arrival. Valid names are `work`, `clients`, `about`, `experience` and `contact`, listed in `SECTIONS` in that file.

## Cursor and scrollbar

On desktops with a mouse, the system pointer is replaced by an accent dot and a trailing ring that grows over links and buttons, modeled on the VerityWave site. It is turned off on touch devices and when the visitor asks for reduced motion. The scrollbar is slim and themed, and its thumb turns mint on hover. Both are styled in [`src/styles/global.css`](src/styles/global.css).

## Theme

A saved choice from the toggle wins. Otherwise the site follows the visitor's system setting, and falls back to dark when the system reports nothing. A small inline script in [`src/layouts/Base.astro`](src/layouts/Base.astro) applies the theme before first paint, so there is no flash. Until the visitor picks a theme, the page also follows live changes to the system setting.

Switching themes works like the Eurovic site: the new theme spreads out from the toggle as a growing circle, using the View Transitions API. The sun and moon icons rotate and swap at the same time. Browsers without View Transitions, and visitors who prefer reduced motion, get an instant switch.

The accent is mint green, set as `--accent` in [`src/styles/global.css`](src/styles/global.css) for each theme.

## Deploying to Cloudflare Pages

1. In the Cloudflare dashboard, go to **Workers & Pages → Create → Pages → Connect to Git** and pick this repository.
2. Set the framework preset to **Astro**, the build command to `npm run build`, and the output directory to `dist`.
3. Add the environment variable `NODE_VERSION` = `22`.
4. After the first deploy, open **Custom domains** and add `devsamc.xyz`, plus `www.devsamc.xyz` if you want it redirected.

Security and cache headers are set in [`public/_headers`](public/_headers).
